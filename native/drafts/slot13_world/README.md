# Private slot13 world draft (terrain + static triangle objects)

`reflex_slot13_world_draft(world, world_bytes, base, base_bytes, deform,
deform_bytes, dt_bits, x87_cw, output, output_bytes)` runs original slot13
(`00444b90`) through the pinned closure in `program.inc`, generated by
`generate_program.py` from `_re/trace/bike_slot13_objects_program.json`.
Instruction semantics are copied verbatim from `../slot13/slot13_draft.cpp`;
only memory, setup and hooks differ. This is private, not a registered ABI.

**Input.** A terrain-v26 `world-<call>.bin` (regions `<u32 address, u32 size,
bytes>`; the first region is the 0x9700-byte simulation), plus the 2048×2048
base and deformation grids (16 MiB each, from
`_re/formats/alpine_collision_world.py`). Regions outside
`0x00400000..0x20000000` are ignored. Writes are allowed only to the
simulation, the nine pointed filters, captured image data and the stack.

**Output.** `0x9700 + 108 + 8` bytes: final simulation, the nine 12-byte
filters in `8b40,8b44,8b48,8e40..8e54` order, LockRect and UnlockRect counts.

Shape pairs other than Triangles-vs-Circle (`8716b0`) and
Triangles-vs-DynamicRays (`86fac0`) are rejected.

```sh
clang++ -std=c++17 -O2 -Wall -Wextra -Werror -fno-fast-math -ffp-contract=off -frounding-math -arch arm64 -o slot13-world-arm64 slot13_world_draft.cpp
clang++ -std=c++17 -O2 -Wall -Wextra -Werror -fno-fast-math -ffp-contract=off -frounding-math -arch x86_64 -o slot13-world-x86_64 slot13_world_draft.cpp
python3 native/drafts/slot13_world/verify.py <terrain-v26 runs...> --output _re/trace/out/slot13-world-native/report.json
```

The command-line tool also accepts `cases=<file>` in place of dt: records of
`<u32 dt, 0x9700 simulation>` used by
`_re/trace/original_generated_slot13_world.py`. Evidence:
`_documentation/slot13-objects-validation.json` and
`_re/notes/slot13-objects-recovery.md`.
