# Original code that reads uninitialized stack

Some original functions read stack bytes they never wrote, usually a vec4's unwritten w lane or a struct's padding. They copy those
bytes into live memory. The bytes are whatever an earlier call left below ESP. The native game must eventually give those reads a
defined value. Until the reader is ported, the port whose dead stack it picks up writes the same bytes (`reflex_game::DeadStack`,
guest.h). This keeps the whole-memory hash identical.

Find a case: Verify shows 0 mismatches but verify.sh says "on: DIFFERENT". Dump both runs (`REFLEX_MEMDUMP=<file>`, with and without
the port) and compare them with `tools/memdiff.py`: it lists the live words that differ and their owning object (RTTI).
